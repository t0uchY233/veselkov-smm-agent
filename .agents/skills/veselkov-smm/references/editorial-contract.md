# Редакционный контракт

Canonical schemas находятся в `docs/generated/contracts/`. Не копируй схему по
памяти: перед импортом проверь JSON по соответствующему файлу.

## План

`plan-document.v1.json` требует заголовок, тезис, 3-12 разделов и целевую
длительность от 5 до 10 минут. Путь передаётся в `release import-plan --file`.

## Bundle

Папка bundle содержит `manifest.json`, обложку и ровно 3-5 файлов визуалов.
Пути assets в manifest относительные, не выходят из папки и не являются URL.

`editorial-bundle.v1.json` проверяет:

- Основной текст по медианной скорости 86 слов в минуту;
- уникальные sources, claims, visuals и anchors;
- источник у каждого существенного факта;
- один anchor каждого визуала в правильном порядке Основного текста;
- четыре стадии `evidence_draft`, `tone_of_voice`, `humanizer`, `lint`;
- hashes входного черновика, текущего TOV и установленного Humanize, перечень
  встроенных Codex tools, SHA-256 чистового текста и ноль Humanize errors;
- один `{{dzen_url}}` и один `{{youtube_url}}` в Telegram CTA;
- 3-5 шагов, ровно три реакции и запас до лимита Telegram после ссылок.

Обложка должна быть 1280 на 720, каждый визуал - 1080 на 1080. Приложение
отклоняет повреждённые изображения и одинаковый файл в двух visual slots.

Приложение производит из Основного текста `teleprompter.txt` с защищённым
приветствием, `dzen.md` без приветствия и DOCX с визуалами на их anchors. Не
создавай расходящиеся копии вручную.

Команда импорта:

```text
smmctl release import-editorial --command-id <uuid> --expected-revision <n> --bundle <path>
```

Каждый повтор использует тот же command ID только для полностью тех же bytes.
