# SMM-агент Сергея Веселкова

Проект автоматизирует подготовку и согласованную публикацию экономических
выпусков в YouTube, Дзен и Telegram. Основной пользователь работает через Codex:
задаёт тему, утверждает материалы, записывает видео и принимает финальный
комплект.

Проект следует artifact-driven AI-native SDLC:

1. [Intent](docs/work/veselkov-smm-agent/intent.md)
2. [7w3-дизайн](docs/work/veselkov-smm-agent/smm-pipeline/smm-pipeline.7w3.md)
3. [Спецификация](docs/work/veselkov-smm-agent/spec.md)
4. [План реализации](docs/work/veselkov-smm-agent/plan.md)
5. реализация и воспроизводимые verification evidence

Пересмотренный 7w3-дизайн и `spec.md` версии 0.2.1 приняты 3 сентября 2026 года.
Реализация ведётся вертикальными сквозными срезами из `plan.md`.

## Безопасность публичного репозитория

В Git не добавляются токены, OAuth credentials, browser profiles, runtime
конфигурация, исходные и готовые видео, рабочие вложения или неопубликованные
артефакты Выпусков. Имя Автора, ссылки на его публичные каналы, TOV и принятые
продуктовые документы опубликованы сознательно. Секретные или runtime-данные
нельзя коммитить даже временно.

## Лицензирование

Публичная доступность репозитория сама по себе не предоставляет лицензию на
использование материалов проекта. Подключённые сторонние компоненты сохраняют
свои лицензии.
