# Ограничения Telegram-публикации

Дата проверки: 2026-09-03

## Подтверждённый результат

В Telegram должен публиковаться нативный видеофайл с согласованной подводкой и
ссылками на YouTube и Дзен того же Выпуска. Публикация ставится в расписание
после финального одобрения Автора и не требует участия Sardor.

## Проверенные ограничения

Официальная документация Telegram Bot API для видео указывает предел подписи:
от 0 до 1024 символов после обработки разметки:
<https://core.telegram.org/bots/api#inputmediavideo>.

Предоставленный образец Telegram-подводки содержит примерно 1331 видимый символ
после удаления служебной Markdown-разметки. Следовательно, полный текст этого
образца не помещается в стандартную подпись к видео.

Для стандартной загрузки файла через облачный Bot API документация также
указывает предел 50 МБ, тогда как локальный Bot API Server допускает загрузку до
2000 МБ: <https://core.telegram.org/bots/api#using-a-local-bot-api-server>.
Фактический размер смонтированного ролика длительностью 5–10 минут пока не
измерен.

## Принятое решение

Telegram-подводка ограничивается 1000 видимыми символами после форматирования и
обработки ссылок. В этот объём должны входить содержательная подводка, CTA со
ссылками на YouTube и Дзен и три строки реакций. Итоговый видеофайл и подводка
публикуются одним сообщением.

## Открытое техническое решение

Необходимо выбрать способ загрузки видео, который выдерживает фактический размер
смонтированного файла.
