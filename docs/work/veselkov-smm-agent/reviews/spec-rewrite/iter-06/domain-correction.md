# Domain correction: scheduled Dzen URL

Date: 2026-09-03

Sardor исправил заложенную в spec неопределённость: при создании отложенной
публикации в Дзене рабочая ссылка на будущий материал уже доступна. Ждать
перехода статьи в public для получения URL не требуется.

Из этого следует принятый порядок:

1. подготовить private YouTube и получить ссылку;
2. создать отложенную публикацию Дзена и получить её ссылку;
3. подставить обе ссылки в утверждённые места Telegram caption;
4. поставить YouTube и Дзен в нативную отложку, Telegram — в Windows Task Scheduler;
5. в target выполнить публикации и восстановить только отсутствующий результат.

Эта запись заменяет URL-dependent publication order из `iter-02/review.md` и
все прежние формулировки о том, что Telegram обязан ждать public-состояния
Дзена. Capability smoke всё ещё обязан проверить селекторы, identity материала,
стабильность полученной ссылки и фактическое состояние отложенной публикации.

Sardor принял остальную спецификацию и разрешил переход к реализации.
