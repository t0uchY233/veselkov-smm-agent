# Контекст проекта

## Автор

**Автор** — Веселков Сергей Николаевич: основной пользователь системы, автор
экономического контента и человек, выступающий в кадре.
_Не использовать как синонимы:_ оператор, администратор, разработчик.

## Выпуск

**Выпуск** — связанный комплект материалов на одну заданную Автором тему,
подготовленный для публикации в YouTube, Дзене и Telegram.
_Не использовать как синонимы:_ статья, ролик, пост — это отдельные части выпуска.

## SMM-агент

**SMM-агент** — проектируемая система, которая проводит один Выпуск через
подготовку текста и визуальных материалов, видеомонтаж и запланированную
публикацию на площадках Автора.
_Не использовать как синонимы:_ чат-бот, видеоредактор, автопостер — это уже,
чем весь проект.

## Текущий агент

**Текущий агент** — уже работающий Codex-агент, созданный Sardor. Автор передаёт
ему тему, а агент готовит материалы, отдаёт DOCX с текстом и визуалами, монтирует
видео и автоматически ставит YouTube-публикацию в расписание. Его реализация
служит исходной точкой для новой версии SMM-агента.
_Не использовать как синонимы:_ новый SMM-агент, полностью ручной процесс.

## Визуальный материал

**Визуальный материал** — подготовленное для Выпуска изображение, диаграмма или
таблица, которое используется в статье и/или в заданном временном отрезке видео.
_Не использовать как синонимы:_ иллюстрация — она является только одним из типов
визуального материала.

## Tone of voice

**Tone of voice** — существующий корпус правил и/или примеров, описывающий
узнаваемую авторскую манеру Сергея Николаевича и используемый для подготовки
текстов от его имени. Канонический файл проекта — `tone-of-voice.md`.
_Не использовать как синонимы:_ тема, фактическая база, редакционная политика.

## Реестр источников

**Реестр источников** — проверяемая часть Выпуска, связывающая каждое
существенное число или актуальное фактическое утверждение с источником и датой
его проверки.
_Не использовать как синонимы:_ список литературы — одного перечня ссылок без
связи с конкретными утверждениями недостаточно.

## Основной текст

**Основной текст** — утверждённая словесная основа Выпуска, одновременно
используемая как речь для телесуфлёра и как содержательная часть статьи в Дзене.
Обязательное видеоприветствие «Здравствуйте, друзья.» стоит перед Основным текстом в
телесуфлёре и не входит в статью Дзена.
_Не использовать как синонимы:_ сценарный план, Telegram-подводка, расшифровка
записанного видео.

## Карта визуалов

**Карта визуалов** — перечень из 3–5 Визуальных материалов Выпуска с привязкой
каждого материала к точке начала соответствующего смыслового фрагмента
Основного текста. При монтаже начавшийся визуал остаётся активным до начала
следующего, а последний — до конца видео.
_Не использовать как синонимы:_ галерея, случайный набор иллюстраций.

## Манифест Выпуска

**Манифест Выпуска** — каноническая машиночитаемая запись одного активного
Выпуска в локальной SQLite-базе: тема, версии и контрольные суммы артефактов,
решения Автора, текущая операция, публикационные идентификаторы и ошибки.
`release.json` является воспроизводимым диагностическим экспортом Манифеста, но
не вторым источником истины. Манифест связывает части одного Выпуска, но не
служит напоминанием между независимыми недельными выпусками.
_Не использовать как синонимы:_ история диалога Codex, SOP, архив материалов.

## Редакционный пакет

**Редакционный пакет** — комплект для второго человеческого gate: Основной
текст, версия телесуфлёра, Дзен-статья, Telegram-подводка, Реестр источников,
3–5 Визуальных материалов, Карта визуалов, обложка и платформенные метаданные.
_Не использовать как синонимы:_ DOCX — это один из форматов представления
пакета, а не сам комплект.

## Целевой канал Дзена

**Целевой канал Дзена** — канал «Экономика не для всех!» в авторизованном
профиле Дзена, доступный для просмотра и редактирования по адресу
`https://dzen.ru/ekonomikadliavseh`. Все статьи Выпусков создаются и ставятся в
отложку только в этом канале. В том же профиле есть отдельный пустой канал
«Админ Экономика не для всех» с пометкой «Основной»; SMM-агент не должен
создавать, редактировать или публиковать в нём материалы.
_Не использовать как синонимы:_ основной канал профиля, канал по умолчанию,
«Админ Экономика не для всех».
## Релиз приложения

**Релиз приложения** — неизменяемая версионная сборка кода SMM-агента,
выпущенная в GitHub Releases и устанавливаемая на ноутбук Автора.
_Не использовать как синонимы:_ Выпуск — это комплект контента, а не версия
программы.

## Релиз приложения

**Релиз приложения** — неизменяемая версионная сборка кода SMM-агента,
созданная GitHub Actions из защищённой ветки и опубликованная в GitHub Releases.
Она используется для установки, диагностики и отката production-системы.
_Не использовать как синонимы:_ Выпуск — это комплект контента Сергея
Николаевича, а не версия программы.
